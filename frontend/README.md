# netmap frontend




```bash
npm install
npm run dev
```

The dev server proxies `/api` to `http://127.0.0.1:6050` (configured in `vite.config.js`), so no CORS setup is required.

## Scripts

```bash
npm run dev      # start the dev server
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # lint with ESLint
```
